# Cancellation Policy

**Category:** Cancellations

**Cancelling a subscription:** Go to Account > Subscriptions > Cancel Subscription. Cancellation takes effect immediately and stops all future shipments and charges. There is no fee to cancel, and you can resubscribe at any time. Unlike pausing, a cancelled subscription is removed from your account and would need to be set up again from scratch if you change your mind.

**Cancelling a one-time order:** Orders can be cancelled for free within **1 hour** of placing them, as long as the order has not yet entered processing. After that window, the order has typically already been picked in our warehouse and cannot be cancelled — you're welcome to refuse delivery or return it once received, per our Returns & Refunds Policy.

To cancel an order within the 1-hour window, go to Order History and select "Cancel Order." If the option is no longer available, the order has already moved to processing.
