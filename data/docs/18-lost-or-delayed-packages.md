# Lost or Delayed Packages

**Category:** Order Issues

If tracking shows a package as "Delivered" but you can't find it, we recommend checking around the delivery location (porches, side doors, mailrooms) and with neighbors or a building's front desk, and waiting 24 hours, since carriers occasionally mark packages delivered slightly before drop-off. If it still hasn't turned up after that, contact support with your order ID and we'll open a carrier trace and typically issue a reshipment or refund within 3-5 business days if the trace confirms it's lost.

If tracking hasn't updated in **5 or more business days** and the order isn't marked delivered, this is considered delayed rather than lost. Contact support with your order ID so we can check the carrier's status directly and provide an updated estimate, or reship if the carrier confirms the package is lost in transit.

Fetchly is not responsible for packages confirmed delivered to the address on file where theft after delivery is suspected, but we're happy to help you file a claim with the carrier in those cases.
