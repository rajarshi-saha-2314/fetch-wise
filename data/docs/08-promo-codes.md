# Promo Codes & Discounts

**Category:** Promotions

Promo codes can be entered at checkout in the "Gift card or promo code" field. Only one promo code can be applied per order, and promo codes cannot be combined with the automatic subscription discount (subscriptions already save 10% off one-time pricing).

Common reasons a code might not work:

- The code has expired (check the fine print in the email or ad it came from).
- The code requires a minimum order value that hasn't been reached.
- The code is for first-time customers only and your account has a prior order.
- The code is restricted to specific product categories (e.g., treats only).

Promo codes cannot be applied retroactively to an order that has already been placed. If a valid code failed to apply and the order has not yet shipped, contact support with the code and order ID and we can review it manually.

Fetchly does not offer price adjustments for promotions that start after an order has already been placed.
